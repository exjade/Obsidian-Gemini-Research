# Añadir y usar la continuidad

## En tu proyecto ChatGPT

1. Descomprime obsidian-research-continuidad.zip. Añade como fuentes SKILL.md y references/ESTADO-CONTINUIDAD.md. Añade PLANTILLA-CONTINUIDAD.md si quieres conservar el formato de entrega.
2. Pega INSTRUCCIONES-PROYECTO-CHATGPT.txt en las instrucciones del proyecto. Adjuntar SKILL.md como fuente no garantiza que se active como una skill nativa: estas instrucciones indican cuándo leerla.
3. Abre un chat y escribe: «Lee SKILL.md y ESTADO-CONTINUIDAD.md. Confirma los archivos disponibles y continúa con revisión humana registrada. Si falta código actual, dime qué archivos adjuntar».
4. Adjunta los scripts y pruebas actuales que solicite. Ya subiste guías, pero éstas no bastan para implementar cambios. Usa la copia del repositorio del commit indicado, no el ZIP baseline antiguo de outputs.
5. Tras cada hito pide un nuevo ESTADO-CONTINUIDAD.md y reemplaza la fuente anterior del estado. Reemplaza también PENDIENTES/ROADMAP/CHANGELOG cuando cambien. Conserva las versiones históricas en Git; evita fuentes activas ambiguas.

La plantilla describe decisiones y pruebas observables. No obliga a recuperar una cadena de pensamiento ni a compartir expedientes privados.

## En un entorno que admite skills de carpeta

La carpeta obsidian-research-continuidad contiene SKILL.md y references/. Puede instalarse en el directorio de skills de ese entorno siguiendo su mecanismo de instalación. Este paquete no instala nada automáticamente. No se cambió tu configuración personal de Codex.

## Cuando vuelva Codex

Entrega el último estado y commit, indica qué archivos cambió ChatGPT/Antigravity y pide revisar la continuidad antes de continuar el siguiente pendiente. La guía CONTINUIDAD-CHATGPT-WEB.md contiene el procedimiento para aplicar parches y validar localmente.

La skill no garantiza límites separados entre productos ni acceso a un modelo específico. Comprueba qué modalidad usas y qué permite tu cuenta.
