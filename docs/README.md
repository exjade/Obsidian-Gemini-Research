# Documentación y memoria con evidencia
El programa ofrece una biblioteca local de investigaciones con Antigravity.
README.md en la raíz enlaza las guías completas de instalación y GitHub.
Abrir-investigacion.cmd inicia la interfaz en Windows bajo demanda.
El servidor escucha en http://127.0.0.1:8765 y no debe exponerse públicamente.
Cada expediente del frontend conserva pregunta, materiales y resultados propios.
Investigator propone hipótesis; Collector busca pruebas; Skeptic intenta refutarlas.
Writer publica únicamente claims VERIFIED con fuentes registradas.
El veredicto no sustituye una revisión humana ni garantiza verdad absoluta.
Los dominios sensibles y claims favorables requieren escrutinio adicional.
Las imágenes y PDF se conservan, pero no se interpretan automáticamente.
El pipeline copia resultados al vault independiente y verifica los bytes.
MCPVault permite lectura del vault; las notas personales no se regeneran.
Datos, expedientes, evidencias y configuración local se excluyen de Git.
Consulta guides/GUIA-COMPLETA.md y guides/GITHUB.md antes de publicar.
